# LU CSE Article

A clean, Markdown-first article repository for sharing technical writing, learning notes, and student-focused content.

## What this project is

This repository is designed for writing blog-style articles in plain Markdown. Each post can include frontmatter metadata, simple sections, links, code examples, and images while staying easy to manage in Git.

## Repository structure

- `posts/` – article files written in Markdown
- `images/` – image assets used by posts
- `demo-article.md` – example article with the expected structure
- `CONTRIBUTING.md` – contribution guidelines and style notes

## Quick start

1. Create a new Markdown file in `posts/`
2. Add the required YAML frontmatter
3. Write the article with clear headings and concise sections
4. Save the file and open a pull request

## Example frontmatter

```yaml
---
title: "Understanding Modern Web Development"
description: "A beginner-friendly introduction to foundational web concepts."
author: "Your Name"
date: "2026-10-14"
category: "Technology"
tags:
  - Web Development
  - Frontend
  - Learning
published: true
featured: false
---
```
